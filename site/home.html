How it works

Five steps,
one command.

  1. 1

    Authenticate

    Anonymous token from the dispenser, rotating device profiles until one works. Or your Google account.

  2. 2

    Fetch details

    Version, size and splits from Google Play's protobuf API.

  3. 3

    Purchase

    "Buy" the free app to get download authorization.

  4. 4

    Get delivery

    Download URLs for base APK, splits, OBB files and asset packs.

  5. 5

    Download

    Stream from Google's CDN in parallel. Asset packs are decompressed on the fly.

FAQ

Questions,
answered.

Is goopdl free?
Yes. goopdl is free and open source under the MIT license. Install it with uv tool install goopdl or pipx install goopdl. It needs Python 3.10 or newer and runs on Linux, macOS and Windows.
Do I need a Google account to download APKs?
No. On first use goopdl gets an anonymous token from Aurora Store's public token dispenser. If you prefer, you can sign in with a throwaway Google account and its AAS token.
How do I download split APKs, OBB files and asset packs?
Run goopdl download com.example.app --splits --extras. --splits adds the split APKs and --extras adds OBB expansion files and Play Asset Delivery packs.
How do I install split APKs on my phone?
After a split download, goopdl prints the exact adb install-multiple command for the files it downloaded. Connect your device and run it.
Can I download an older or a specific version?
Yes. Pass a version code (-v 231205015) or a version string (-v 434.0.0.44.74). For a version string, goopdl tries fresh GSF IDs until one of them sees that version.
How do I get the newest version during a staged rollout?
Run goopdl latest com.example.app. Google rolls updates out by device cohort, so goopdl asks through several GSF IDs and keeps the highest version code it sees.
Which devices and architectures are supported?
arm64 (the default), armv7, x86, x86_64 and Android TV (tv), chosen with --arch. Comma-separate several to get one download per architecture.
How do I get the version of an app for another country?
Combine --country with a --proxy located in that country. --country on its own only changes the region headers.
Can I verify the downloaded files?
Yes. --integrity-manifest checks every base and split APK against Google's digests (SHA-256, or SHA-1 when that's all Google sends) and writes a JSON manifest. Google sends no digests for OBB files and asset packs, so those aren't verified.
What happens if I get rate-limited?
goopdl keeps a pool of 5 anonymous tokens per architecture and country and only asks for missing ones, which keeps it under the dispenser's limit of about 20 requests per hour. If Google Play answers HTTP 429, goopdl retries the delivery request twice, then exits with code 5. For high-volume use there is goopdl fast-download.
